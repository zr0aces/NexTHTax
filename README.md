# NexTHTax — แฟ้มภาษีที่คุณดูแลเอง

เว็บแอปภาษาไทยสำหรับเก็บเอกสารและประมาณภาษีบุคคลธรรมดา เริ่มปี **2569** เพิ่มปีถัดไปได้ ไม่มีบัญชีผู้ใช้ ไม่มี backend รับข้อมูลภาษี ไม่มี analytics หรือ external AI

> ใช้ช่วยเตรียมยื่น ไม่ใช่แบบยื่นทางการ ไม่รับรอง ภ.ง.ด.90 ทุกกรณี กฎที่ยังไม่ยืนยันเก็บเอกสารได้แต่ไม่นับสิทธิ

## เว็บไซต์สาธารณะ

เปิดแอป: **https://zr0aces.github.io/NexTHTax/**

GitHub Actions ใน `.github/workflows/pages.yml` ตรวจ TypeScript/tests และ build เมื่อ push เข้า `main` แล้วเผยแพร่เฉพาะ `dist/` ไป GitHub Pages ไม่เผยแพร่แฟ้มภาษีของผู้ใช้ `examples/` ใน source repository เป็นข้อมูลสมมติเท่านั้น

## เปิดใช้งาน

ต้องมี Node.js 22.13+ (แนะนำ 24 LTS) และ npm

1. `npm ci`
2. `npm run dev` แล้วเปิด URL ที่แสดง เพื่อพัฒนา
3. `npm run build` สร้าง static app พร้อม offline cache ใน `dist/`
4. `npm run preview` เพื่อทดลอง **ฉบับ build** ในเครื่อง (ออฟไลน์ไม่ทำงานใน dev)

นำ **เนื้อหาทั้งหมด** ของ `dist/` ไปวางบน static hosting ที่รองรับ HTTPS ได้ ไม่มี server-side runtime หรือ database รองรับการวางใน subdirectory ที่เปิดผ่าน URL ลงท้าย `/` ไม่ต้องดับเบิลคลิก HTML และไม่ต้องติดตั้ง PWA

การโหลดแอปครั้งแรกใช้ network เพื่อโหลดโปรแกรม ฟอนต์ ไอคอน และทรัพยากร PDF ที่รวมมา ไม่ใช่การส่งข้อมูลภาษี กดอ้างอิงทางการจึงเปิดเว็บภายนอกตามการกระทำของผู้ใช้

## เริ่มบันทึกรายการแรก

1. กด **สร้างแฟ้มภาษีใหม่** เลือกโฟลเดอร์ว่าง หรือโหมด ZIP
2. ค่าเริ่มต้นคือปี 2569 ยังไม่ต้องกรอกรายได้ก็ได้
3. กด **เพิ่มรายการ** เลือกหมวด กรอกชื่อ ยอดเงิน วันที่ แล้วบันทึก แนบเอกสารทีหลังได้
4. เมื่อต้องการประมาณภาษี ใส่รายได้ทั้งปีก่อนหัก และเลือกเงินเดือน/รายได้อื่น
5. เปิด **ดูเงื่อนไขและตรวจสิทธิ** ของรายการ แล้วตรวจสิทธิแยกจาก checklist เอกสาร

สำหรับครอบครัวบางสิทธิ ให้กรอกจำนวนผู้เข้าเกณฑ์แทนการใช้ยอดจ่ายจริง เช่น บุตร บิดามารดา ใช้ **หนึ่งรายการรวมทั้งปีต่อสิทธิ** ตามข้อจำกัดที่แสดง การเพิ่มหลักฐานในรายการเดิมไม่สร้างยอดจ่ายซ้ำ

## สองโหมดบันทึก

| | โฟลเดอร์โดยตรง | ZIP |
|---|---|---|
| การรองรับ | Chrome/Edge desktop ที่มี File System Access + Web Locks บน HTTPS/localhost | Browser สมัยใหม่ที่อ่านไฟล์และดาวน์โหลด ZIP ได้ รวม Safari/Firefox |
| ที่เก็บขณะทำงาน | หน่วยความจำ แล้วบันทึกลงโฟลเดอร์ที่เลือกจริง | หน่วยความจำเท่านั้น |
| เมื่อแก้ไข | บันทึกหลังหยุดแก้ชั่วครู่ สถานะสำเร็จหลัง write/close/readback จริง | แสดงว่ายังไม่ส่งออก ต้องกด **ส่งออก ZIP** |
| กลับมาทำต่อ | กด **เปิดแฟ้มภาษีเดิม** เลือกโฟลเดอร์ที่มี manifest | กด **เปิดแฟ้ม ZIP** เลือกฉบับล่าสุด |

- แอปตรวจความสามารถจริง ไม่รับประกันจากชื่อ browser เพียงอย่างเดียว มือถือหรือบริบทไม่รองรับให้ใช้ ZIP
- เปิดแอปใหม่อาจต้องเลือกโฟลเดอร์และให้สิทธิใหม่ เป็นพฤติกรรม browser ไม่ใช่ข้อมูลหาย
- โหมด ZIP ไม่เรียกการแก้ในหน่วยความจำว่า auto-save หลังส่งออกให้ตรวจรายการดาวน์โหลด แอปไม่ทราบว่าผู้ใช้เก็บไฟล์สำเร็จหรือยกเลิก
- มี beforeunload เตือนเมื่อมีงานค้าง แต่ browser/ระบบมือถืออาจไม่แสดงเสมอ อย่าพึ่งการเตือนแทนการสำรอง
- ปุ่มส่งออกทั้งแฟ้มในหน้า **เตรียมยื่นภาษี** ใช้สำรองได้แม้เป็นโหมดโฟลเดอร์

## เปิดแฟ้มเดิม ย้ายเครื่อง สำรอง และกู้คืน

- ย้าย **ทั้งโฟลเดอร์** หรือส่งออก ZIP แล้วเปิดอีกเครื่อง เอกสารอ้าง relative paths ไม่ผูกกับตำแหน่งเดิม
- สำรอง ZIP ต่างที่ก่อนแก้สำคัญ เก็บฉบับเก่าไว้ด้วย ZIP มีข้อมูลและเอกสารทุกปี พร้อม `index.html` สำหรับ Ctrl+F หลังคลายไฟล์
- ในโหมดโฟลเดอร์มี `.tax-backup.zip` ของฉบับก่อนบันทึกล่าสุด เมื่อบันทึกไม่สมบูรณ์จะมี `.tax-pending.json` และหยุดเปิดแฟ้มที่อาจไม่ตรงกัน
- กู้คืนผ่าน **กฎและวิธีใช้งาน → กู้คืนสำรองของโฟลเดอร์** ยืนยันก่อนแทนที่ข้อมูลปัจจุบันด้วยฉบับสำรอง
- การสร้างครั้งแรกล้มเหลวยังไม่มีฉบับก่อนหน้า ให้เลือกโฟลเดอร์ว่างใหม่ ไม่ลบไฟล์เดิมอัตโนมัติ
- รุ่นข้อมูลที่ไม่รองรับถูกปฏิเสธ ไม่แปลงหรือเขียนทับอัตโนมัติ รุ่นแรกยังไม่มีเส้นทาง migration เพราะมีรูปแบบเดียว
- พบไฟล์แนบหายจะแจ้งและลดสถานะเอกสาร ไฟล์ที่ hash เปลี่ยนจะไม่เปิดเป็นฉบับปกติ ให้ใช้สำรองตรวจคืน
- ห้ามแก้ไฟล์ด้วยโปรแกรมอื่นระหว่างบันทึก แอปล็อกการอ่าน/เขียนข้ามแท็บและตรวจ hash ก่อน/หลังเขียน แต่ไม่สามารถล็อกทุกโปรแกรมหรือระบบซิงก์ภายนอกได้
- ลบรายการหรือนำไฟล์ออกจากรายการ **ไม่ลบไฟล์เอกสารที่คัดเข้ามาแล้ว** เพื่อรักษาหลักฐาน แนบไฟล์เดิมที่ไม่มีรายการอ้างอิงกลับมาได้โดยใช้ไฟล์เก็บเดิม ไม่แตะต้นฉบับนอกแฟ้ม

**ข้อมูลและเอกสารบันทึกในโฟลเดอร์ที่คุณเลือก** หากโฟลเดอร์อยู่ใน OneDrive/iCloud/บริการซิงก์อื่น ระบบนั้นอาจส่งข้อมูลตามการตั้งค่าของคุณ แอปควบคุมการซิงก์นั้นไม่ได้ JSON และเอกสารไม่ได้เข้ารหัส โปรดเก็บในพื้นที่ที่ปลอดภัย

## เพิ่มปี และเปลี่ยนชุดกฎ

- กด `+` ข้างปี เลือกปีใหม่ เลือกคัดลอกหมวดที่สนใจได้โดยยืนยัน ไม่คัดลอกรายได้ รายจ่าย เอกสาร หรือสถานะตรวจครบ
- ปี 2570 เป็นต้นไปเริ่มด้วย **กฎภาษีปีนี้ยังไม่ยืนยัน** ไม่มีการใช้เพดานหรือขั้นภาษีปีก่อนเงียบ ๆ
- กฎแต่ละปีเก็บ snapshot ในแฟ้ม การอัปเดตโปรแกรมไม่เปลี่ยน snapshot เดิม
- นำเข้าชุดกฎในเมนูรอง ตรวจรูปแบบ/รุ่น/ปี/วงเงิน/ลำดับ ดูผลต่าง และกดยืนยันหลังสำรอง รายการที่เงื่อนไขเปลี่ยนต้องตรวจสิทธิใหม่
- การผ่านการตรวจไฟล์ **ไม่ใช่การรับรองกฎหมายหรือผู้ออกไฟล์** ต้องตรวจแหล่งอ้างอิงเอง
- สิทธิต่อเนื่อง ESGX ต้องระบุแหล่งสับเปลี่ยน ยอดสับเปลี่ยน และยอดใช้สิทธิปีแรก พร้อมยืนยันหลักฐาน ป้องกันแหล่งเดียวกันซ้ำในปี และตรวจข้อมูลต้นทางให้ตรงกันข้ามปี

## ภาษีและขอบเขต

รายละเอียดแหล่งทางการ/ช่วงมีผล: [ตารางตรวจสอบกฎ 2569](docs/tax-research-2569.md) · ชุดกฎ: [`public/rules/2569.json`](public/rules/2569.json)

- เงินทั้งหมดใช้ **สตางค์จำนวนเต็ม** สัดส่วนใช้ BigInt; ภาษีก้าวหน้ารวมก่อนยกเว้นเศษบาทสุดท้ายตาม พ.ร.ฎ.10/2500 มาตรา 5
- ค่าใช้จ่ายเงินเดือน 50% สูงสุด 100,000; เปรียบเทียบภาษีก่อน/หลังโดยรวมส่วนตัว 60,000 ในฐานทั้งคู่แล้ว ภาษีประหยัดเป็นผลต่างการคำนวณจริง
- แยกสิทธิ verified/pending/expired เอกสารครบไม่ทำให้สิทธิผ่านเอง คิดเฉพาะรายการที่ผู้ใช้ตรวจยืนยันและกฎยืนยันแล้ว
- มีเพดานชีวิต/สุขภาพ เกษียณ ESG ร่วม และลำดับบริจาคเฉพาะที่ตรวจแล้ว ไม่บวกวงเงินเหลือแต่ละหมวดเป็นสิทธิรวม
- ประกันบำนาญจัดส่วนเข้าเพดานชีวิตที่ยังเหลือก่อน แล้วใช้ส่วนที่เหลือในกลุ่มบำนาญ/เกษียณ หรือระบุส่วนจัดสรรเอง ไม่ใช้เบี้ยเดียวกันซ้ำ
- รายได้อื่นไม่ใช้สูตรค่าใช้จ่ายเงินเดือนเอง เลือกดูวงเงินก่อน หรือระบุค่าใช้จ่ายที่ตรวจตามประเภทแล้วเพื่อประมาณเฉพาะอัตราก้าวหน้า
- ไม่คำนวณภาษีขั้นต่ำมาตรา 48(2), เครดิตภาษีต่างประเทศ, ภาษียื่นรวมคู่สมรส หรือความซับซ้อนของ ภ.ง.ด.90 ทุกกรณี วิธีปัดเศษย่อยทุกช่อง/ขั้นตอนหักเครดิตยังไม่รับรองเทียบแบบยื่นจริง
- ครอบครัวใช้จำนวนผู้เข้าเกณฑ์ที่ผู้ใช้ยืนยัน ไม่ตรวจทะเบียนบุคคล ไม่ขอเลขบัตร/วันเกิดเต็ม; บ้านรองรับหนึ่งยอดรับรองรวมทั้งปีและจำนวนผู้กู้เท่ากัน หากหลายสัญญาต่างสัดส่วนยังไม่คำนวณอัตโนมัติ
- ESGX ต่อเนื่องที่ยอดใช้สิทธิปีแรกไม่เท่ากับขั้นต่ำของยอดสับเปลี่ยนกับ 300,000 ยังรอตรวจ ไม่ยกยอดที่ไม่ได้ใช้ปีแรกเอง
- ตัวอย่างสิทธิยังไม่เปิดคำนวณ: ฝากครรภ์ที่ต้องติดตามข้ามปี, ยกเว้นอายุ/พิการ, ม.39/40, กองทุนครู, วิสาหกิจเพื่อสังคม, Solar Rooftop และมาตรการเฉพาะปีที่ตรวจเงื่อนไขไม่ครบ ดูรายการจริงจากชุดกฎ ไม่ถือว่าทะเบียนนี้รับรองสิทธิทุกกรณีในปี 2569
- SSF/LTF เดิม เอกสารรายได้และแบบยื่น หมวดกำหนดเอง เป็นที่เก็บเอกสาร ไม่เพิ่มสิทธิโดยอัตโนมัติ
- ยอดจำลองไม่แก้รายการจริง ไม่มีการแนะนำให้ซื้อผลิตภัณฑ์เพื่อเต็มวงเงิน

## ส่งออกและออฟไลน์

หน้า **เตรียมยื่นภาษี** มี PDF สรุป (ผ่านหน้าต่างพิมพ์ → Save as PDF), CSV รายการ, CSV เอกสารขาด และ ZIP ทั้งแฟ้ม ไม่มีการส่งแบบไปกรมสรรพากร

PDF ใช้ Kanit ที่รวมในแอป ทดสอบไฟล์ PDF จริง อ่านข้อความไทยกลับและ render ตรวจภาพแล้ว การ preview PDF ใช้ PDF.js วาด canvas ในเครื่อง ไม่รัน JavaScript/ลิงก์/แบบฟอร์มของเอกสาร

เมื่อข้อความ **เตรียมไฟล์แอปสำหรับออฟไลน์แล้ว** ปรากฏจึงปิดเน็ตได้ Service worker เก็บเฉพาะ asset ที่อยู่ใน static build รวมฟอนต์และตัวอ่าน PDF ไม่เก็บข้อมูลภาษีใน Cache/IndexedDB/localStorage ไม่ cache request ขณะใช้งานเพิ่ม เปิดแฟ้มเดิมหลัง reload ด้วยโฟลเดอร์หรือ ZIP ของคุณเสมอ อย่าล้าง site data ก่อนใช้ออฟไลน์ โปรแกรมรุ่นใหม่เริ่มใช้หลังปิดแท็บเดิมทั้งหมดแล้วเปิดใหม่

## ความปลอดภัยและขีดจำกัด

- เอกสาร PDF/JPG/PNG/WebP ตรวจนามสกุล MIME และ magic bytes, SHA-256 ภายในเครื่อง เตือนเอกสารซ้ำก่อนนับรายการ
- ไม่เกิน 20 MB/ไฟล์, 20 ไฟล์/รายการ, 500 เอกสารและ 200 MB เอกสารรวม/แฟ้ม, 5,000 รายการ/ปี, 150 หมวด/ปี, 100 ปี/แฟ้ม
- ZIP ไม่เกิน 220 MB และจำกัดขนาดคลายไฟล์ ตรวจ path/CRC/ดัชนี ไม่รองรับ ZIP64, ZIP เข้ารหัส หรือ archive หลายส่วน
- ปฏิเสธ path traversal/ZIP slip และชื่อไฟล์อันตราย แยกเอกสารเป็นไฟล์จริงไม่ใส่ base64 ใน JSON, CSV ป้องกันสูตรจากชื่อรายการ
- เปิดเอกสาร PDF ที่มีรหัสผ่าน/เสียหรือใหญ่เกินขอบเขต preview ไม่ได้ ให้ตรวจต้นฉบับด้วยโปรแกรมที่เชื่อถือได้

- `npx playwright install --with-deps chromium` สำหรับเครื่องที่ยังไม่มี browser ทดสอบ แล้ว `npm run test:e2e`
