# NexTHTax: เอกสารภาษีบนเครื่อง

เว็บสำหรับบุคคลธรรมดาเก็บเอกสารภาษี (เงินเดือน หนังสือรับรอง 50 ทวิ ค่าลดหย่อน เงินบริจาค การลงทุน)
ไม่ต้องสมัครสมาชิก ข้อมูลและไฟล์แนบเก็บในโฟลเดอร์ที่คุณเลือกบนเครื่องนี้

แอปไม่คำนวณภาษีสุทธิ ไม่ยื่นภาษีแทนคุณ และไม่รับรองสิทธิหรือความครบถ้วนของการยื่น

## การใช้งาน

- ใช้ Chrome หรือ Edge บนคอมพิวเตอร์ (Safari, Firefox และมือถือยังไม่รองรับการแก้ไข)
- ต้องเปิดผ่าน HTTPS หรือ `localhost`
- เลือก "เปิดโฟลเดอร์ข้อมูลที่มีอยู่" หรือ "เลือกโฟลเดอร์ว่างเพื่อเริ่มใหม่"
- **คำนวณและวางแผน**: กรอกข้อมูลเงินเดือน แล้วกด "บันทึกข้อมูลภาษี" ก่อนตรวจผลจากข้อมูลที่บันทึก บันทึกแผนเบี้ยประกันสุขภาพเพิ่มได้หนึ่งแผนต่อปี โดยระบุยอด งบประมาณ สิทธิ เงื่อนไขและสภาพคล่อง แล้วกด "บันทึกแผน"
- **เอกสาร**: เพิ่มหรือแก้ไขหลักฐาน ดูความคืบหน้าและยอดรวมได้จาก "สรุปเอกสารและความคืบหน้า" เอกสารบันทึกอัตโนมัติหลังหยุดพิมพ์ 0.5 วินาที
- **เครื่องมือ**: ตรวจสอบกฎภาษี สำรอง ZIP และกู้คืนข้อมูล
- เลือกปีภาษีจากช่องเดียวด้านบน ใช้ปีเดียวกันทุกหน้า แอปถามก่อนละทิ้งข้อมูลภาษีที่ยังไม่บันทึก
- สถานะ "บันทึกแล้ว" หมายถึงแอปอ่านไฟล์กลับมาตรวจแล้วเท่านั้น

การติดตามแผน: เปิด "ติดตามการชำระและหลักฐาน" กรอกยอดจ่ายจริง ยืนยันการชำระ และเลือกเอกสารประกันสุขภาพปีเดียวกันที่ตรวจทานแล้วพร้อมไฟล์แนบ จากนั้นกด "ยืนยันทำรายการครบแล้ว" แอปตรวจยอดและไฟล์แนบ ข้อมูลหรือหลักฐานที่เปลี่ยนจะทำให้ต้องตรวจสอบใหม่ การทำรายการครบไม่ใช่การรับรองสิทธิลดหย่อน

ยอดของแผนเป็นยอด **เพิ่มเติมจากข้อมูลภาษีตั้งต้น** ต้องยืนยันว่ายังไม่รวมในใบคำนวณ และห้ามใช้หลักฐานเดียวกับที่ผูกในใบคำนวณซ้ำ แอปไม่ย้ายยอดจ่ายจริงเข้าใบคำนวณให้อัตโนมัติ แสดงประมาณการตามแผนและรายการที่ทำครบแยกกัน กฎที่ยังไม่ยืนยันจะไม่แสดงยอดประหยัดภาษี กำหนดเวลาที่ยังไม่มีแหล่งยืนยันแสดงว่า "ยังไม่ยืนยัน" ไม่เดาวันให้

รายละเอียดขอบเขตและส่วนที่ยังรอการยืนยันกฎปี 2026: [Simple tax planning](plans/2026-10-25-no-issue-simple-tax-planning.md)

## ความเป็นส่วนตัว

- ข้อมูลผู้เสียภาษี JSON และไฟล์แนบอยู่ในโฟลเดอร์ที่คุณเลือกเท่านั้น
- ไม่มีการส่งข้อมูลไปยัง cloud, OCR ระยะไกล, analytics หรือ telemetry
- แอปไม่เข้ารหัสข้อมูลเอง ใช้การเข้ารหัสดิสก์และบัญชีผู้ใช้ของระบบปฏิบัติการ
- โฟลเดอร์ที่ซิงก์คลาวด์ (OneDrive, Google Drive, Dropbox ฯลฯ) อาจอัปโหลดไฟล์เองตามการตั้งค่าของระบบ แอปตรวจไม่ได้ทั้งหมด
- เว็บไซต์ที่โฮสต์แอปอาจบันทึก IP ของผู้เข้าชมเพื่อความปลอดภัย ข้อมูลผู้เสียภาษีไม่ถูกส่งจากแอป

## สำรองและกู้คืนข้อมูล

- **สำรอง ZIP ทั้งหมด**: รวมข้อมูล ไฟล์แนบ ถังขยะ กฎที่ปักไว้ และไฟล์กู้คืน พร้อมรายการ hash ตรวจสอบได้
- **กู้คืน ZIP**: เลือกโฟลเดอร์ว่างใหม่เท่านั้น โฟลเดอร์เดิมไม่ถูกแก้ไข
- **ส่งออก JSON**: เฉพาะข้อมูลรายการ ไม่รวมไฟล์แนบ ไม่ใช่ข้อมูลสำรองครบถ้วน
- **นำเข้า JSON**: ต้องใช้โฟลเดอร์ว่างใหม่ ไฟล์แนบจะแสดงว่าหายจนกว่าจะเลือกไฟล์ใหม่ (การเชื่อมไฟล์ใหม่ยังไม่มีในรุ่นนี้)
- โปรดสำรอง ZIP เป็นระยะ และก่อนลบถาวรหรือย้ายโฟลเดอร์
- ขีดจำกัดของรุ่นนี้: ข้อมูลทั้งหมดในโฟลเดอร์รวมกันไม่เกิน 768 MiB, ไฟล์แนบแต่ละไฟล์ไม่เกิน 100 MiB, ไฟล์ metadata แต่ละไฟล์ไม่เกิน 20 MiB, ไฟล์ 8,000 รายการ และ ZIP ไม่เกิน 1 GiB / 10,000 รายการ ถ้าข้อมูลเกินขีดจำกัด แอปจะปฏิเสธการเปลี่ยนแปลงโดยไม่ลบข้อมูลเดิม

## ข้อจำกัดของเบราว์เซอร์และการเขียนไฟล์

- หนึ่งหน้าต่างเป็นผู้เขียนต่อโฟลเดอร์ (ประสานด้วย Web Locks ภายใต้ origin และโปรไฟล์เดียวกัน) หน้าต่างที่สองเปิดอ่านได้อย่างเดียว
- แอปตรวจการเปลี่ยนแปลงจากภายนอกก่อนเขียน แต่ไม่ใช่การเปรียบเทียบแบบอะตอมิก ยังมีช่วงเวลาสั้น ๆ ระหว่างการตรวจกับการเขียนที่โปรแกรมอื่นอาจแก้ไขไฟล์ได้
- ไม่ป้องกันการเขียนจากโปรแกรมอื่น โปรไฟล์อื่น หรือเครื่องอื่น
- "บันทึกแล้ว" หมายถึงเบราว์เซอร์เขียนและอ่านกลับตรวจสอบแล้ว ไม่รับประกันการเขียนถึงฮาร์ดแวร์เมื่อไฟดับ
- ถ้าบันทึกไม่สำเร็จ ข้อมูลล่าสุดยังอยู่ในหน้าจอ ให้แก้สาเหตุ (สิทธิ์โฟลเดอร์หรือพื้นที่ดิสก์) แล้วบันทึกใหม่ หรือส่งออกข้อมูลฉุกเฉิน (JSON ไม่ใช่สำรองครบ และไม่รวมค่าที่กรอกไม่ถูกต้อง)

## กฎภาษีรายปี

- กฎแต่ละปีมีเวอร์ชัน วันที่ตรวจทาน และแหล่งอ้างอิง ยอดที่คุณกรอกไม่เปลี่ยนเมื่อเปลี่ยนกฎ
- การเปลี่ยนเวอร์ชันกฎต้องยืนยันก่อน
- ป้าย "ยืนยันแล้ว" ใช้เฉพาะเมื่อเวอร์ชันและ digest ตรงกับรายการที่แอปรุ่นนั้นมาพร้อมและผ่านการตรวจทานแล้ว
- ปัจจุบันรุ่นนี้ยังไม่มีกฎที่ตรวจกับแหล่งทางการ หมวดทั้งหมดแสดงว่า "ยังไม่มีกฎที่ตรวจแล้ว" และไม่คำนวณยอดสิทธิหลังกฎ
- ปีที่ยื่นและกฎที่ใช้ควรตรวจกับกรมสรรพากรและราชกิจจานุเบกษาโดยตรงทุกต้นปีและเมื่อมีประกาศใหม่

## ประเภทเอกสารย่อย

- ประเภทย่อยมีเฉพาะหมวด "กองทุนลดหย่อน" (RMF, ThaiESG, กองทุนอื่น ๆ) และ "ประกัน" (ชีวิต, บำนาญ, สุขภาพ, อื่น ๆ) "ยังไม่ระบุประเภท" คือค่าว่างของรายการ ไม่ใช่ประเภทใหม่
- ประเภทย่อยใช้จัดกลุ่มและค้นหาเอกสารเท่านั้น ไม่ใช่การรับรองสิทธิลดหย่อนและยังไม่มีการคำนวณภาษีในรุ่นนี้
- ข้อมูลรุ่นเดิม (schema 1 หรือ 2) เปิดดูและแก้ไขในโฟลเดอร์เดิมได้ทันที การบันทึกคง schema เดิมไว้ ไม่แปลงข้อมูลหรือบังคับสร้างสำเนาเมื่อเปิด ข้อมูลเก่าจึงยังใช้กับแอปรุ่นที่รองรับรูปแบบเดิมได้
- Schema 1 แก้ไขเอกสารและไฟล์แนบได้ ส่วน schema 2 แก้ไขประเภทย่อยและใบคำนวณได้ด้วย โดยคงทางเลือกเดิมไว้ หากต้องการคุณสมบัติที่รูปแบบเดิมเก็บไม่ได้ เช่น แผนใหม่ ให้เลือก "สร้างสำเนาสำหรับคุณสมบัติใหม่" แล้วเลือกโฟลเดอร์ว่างสำหรับ schema 3 ต้นฉบับและไฟล์กู้คืนเดิมคงเดิม สำเนาใหม่เปิดด้วยแอปรุ่นเก่าไม่ได้ การนำเข้า JSON/ZIP รุ่นเดิมยังต้องยืนยันการแปลงเป็นสำเนาใหม่
- การนำเข้า JSON/ZIP ล้างการยืนยันใบคำนวณ ทางเลือก และการทำรายการครบ ต้องตรวจและยืนยันใหม่ ไฟล์แนบยังตรวจ hash ก่อนยืนยันการทำรายการ
- ใบคำนวณที่นำเข้ามีรายละเอียดหรือการเชื่อมหลักฐานเกินหน้าจอแบบง่าย จะไม่ถูกบันทึกทับจากหน้าจอนี้ เพื่อไม่ให้ข้อมูลที่ซ่อนอยู่สูญหาย
- ไฟล์ CSV เพิ่มสองคอลัมน์ท้ายจาก 10 คอลัมน์เดิม ได้แก่ "รหัสประเภทเอกสารย่อย" และ "ประเภทเอกสารย่อย" โปรแกรมที่บังคับจำนวนคอลัมน์ต้องปรับตาม
